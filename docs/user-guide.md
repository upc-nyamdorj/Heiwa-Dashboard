# Heiwa Төслийн Dashboard — хэрэглэгчийн гарын авлага

Энэ бол самбарыг өдөр тутам ашиглах хүмүүст зориулсан заавар. Тохиргоо,
хөгжүүлэлтийн талаар [`technical-guide.md`](technical-guide.md)-ээс үзнэ үү.

Самбарын хаяг: **https://heiwa-dashboard.nyamdorj-m.workers.dev**

---

## 1. Нэвтрэх

Хаягийг нээхэд эхлээд нэвтрэх дэлгэц гарна. Хэрэглэгчийн нэр, нууц үгээ
оруулаад **Нэвтрэх** дарна.

Анхаарах зүйлс:

- **Хэрэглэгчийн нэрийн том/жижиг үсэг хамаагүй.** `Bat`, `bat`, `BAT` гурвыг
  ижилд тооцно. Нууц үгийн хувьд том/жижиг үсэг **чухал**.
- **Нэвтрэлт 12 цаг үргэлжилнэ.** Дараа нь дахин нэвтэрнэ.
- Нэр, нууц үгийн аль нь буруу байсныг систем заадаггүй — хоёуланд нь ижил
  хариу өгнө. Энэ нь хэн бүртгэлтэйг гаднаас таах боломжийг хаах зорилготой.
- Акаунт нь зөвхөн Админ үүсгэнэ. Өөрөө бүртгүүлэх боломжгүй.

Нэвтэрсний дараа баруун дээд буланд таны нэр, эрх (жишээ нь
`nyamdorj.m@upc.mn · Админ`) харагдана. Хажууд нь **Гарах** товч байна.

Эрх нь өсөн нэмэгддэг: Админ бүх зүйлийг хийнэ, Синхрончлогч Харагчийн бүх
зүйлийг хийнэ.

> шинэчлүүлнэ. Хэрэв бүх хэрэглэгч өөрөө солих шаардлагатай бол энэ хэсгийг
> тусад нь гаргах хэрэгтэй.

**Эрх өөрчлөгдвөл шууд үйлчилнэ.** Админ таны эрхийг өөрчилбөл нэвтрэлт
дуусахыг хүлээхгүйгээр дараагийн даралт дээр шинэ эрх хүчин төгөлдөр болно.
Таб нуугдах, эсвэл үйлдэл татгалзагдах байдлаар мэдрэгдэнэ.

## 3. Табууд юу харуулдаг вэ

Зүүн талын цэснээс сонгоно. Сонгосон таб хаягийн мөрөнд `#contracts` маягаар
бичигдэх тул тухайн таб руу шууд холбоос илгээж болно.

| Таб | Агуулга |
|---|---|
| **Тойм** | Гэрээний нийт дүн, санхүүжилтийн урсгал, гэрээт талуудын эрэмбэ, эрсдэлийн үнэлгээ, гэрээний хугацааны Gantt |
| **Гэрээ** | Гэрээний бүртгэл, нэмэлт өөрчлөлт, санхүүжилтийн гүйцэтгэл хувиар. Мөр дээр дарахад тухайн гэрээний төлбөрийн задаргаа нээгдэнэ |
| **Санхүүжилт** | Төлбөрийн тайлангийн дэвтэр, сарын cash-flow, төрөл болон талаар задаргаа |
| **Баримт бичиг** | Бүх файлын бүртгэл, ангилал × төрлийн матриц, дугаарлалтын хяналт |
| **Захидал / RFI** | Ирсэн/явсан захидлын урсгал, RFI-д хариу өгөх хугацаа, чанарын баримт (акт, торгууль) |
| **Зургийн бүртгэл** | Зургийн багц, хуудасны тоо, блокоор задаргаа, зохиогчийн статус |
| **Шалгалт** | Өгөгдлийн үнэн зөв байдал: автомат шалгалтын үр дүн, талбар бүрийн эх сурвалж, гараар шалгах жагсаалт |
| **Баталгаажуулах** | *(зөвхөн Админ)* AI-аар задалсан шинэ баримтыг батлах дараалал |
| **Хэрэглэгчид** | *(зөвхөн Админ)* Акаунт үүсгэх, эрх өөрчлөх, нууц үг шинэчлэх, устгах |

Баруун дээд булангийн нар/сар тэмдэгтэй товчоор цайвар/бараан горим солино.
Сонголт нь тухайн браузерт хадгалагдана.

## 4. Баримтын эх файлыг OneDrive-д нээх

Хүснэгтийн мөрийн төгсгөлд жижиг холбоосын тэмдэг (↗) байвал дарахад тухайн
баримтын **эх PDF файл SharePoint дээр шинэ табд нээгдэнэ**.

- Тэмдэг нь **зөвхөн эх файлын холбоос мэдэгдэж байгаа мөрөнд** гарна. Мэдэгдэхгүй
  бол тэмдэг огт харагдахгүй — идэвхгүй товч харуулахгүй.
- Хэрэв тухайн хүснэгтийн **нэг ч мөрөнд** холбоос байхгүй бол баганыг бүхэлд нь
  харуулахгүй.
- Файл нээхэд **Microsoft акаунтаараа (@upc.mn) нэвтрэх шаардлагатай**. Энэ нь
  самбарын нэвтрэлтээс тусдаа зүйл — SharePoint өөрөө шалгадаг.

> **Одоогийн байдал.** Холбоос нь sync-ээр орж ирээд батлагдсан баримтуудад
> автоматаар үүснэ. Түүнээс өмнөх хуучин мөрүүдэд холбоос байхгүй тул одоогоор
> тэмдэг харагдахгүй. Хуучин мөрүүдийг ч холбохын тулд Админ нэг удаагийн
> backfill ажиллуулна — [`technical-guide.md`](technical-guide.md)-ээс үзнэ үү.

## 5. Sync товч *(Синхрончлогч, Админ)*

Баруун дээд буланд эргэх сумтай товч байна. Дарахад баталгаажуулах цонх гарч,
**Эхлүүлэх** дарснаар OneDrive-аас шинэ баримт хайх ажиллагаа эхэлнэ.

Юу болох вэ:

1. SharePoint дахь хавтсыг уншиж, өмнөх удаагаас хойш нэмэгдсэн/өөрчлөгдсөн
   файлыг олно.
2. Тэдгээрийг татаж, Claude API-аар агуулгыг задалж уншина.
3. Үр дүнг **Баталгаажуулах** табын дараалалд оруулна — өгөгдлийн санд шууд
   ордоггүй.

Анхаарах зүйлс:

- **Задлалт төлбөртэй.** Файл бүрийг AI уншдаг тул шаардлагагүй үед дарах нь
  зардал гаргана. Тиймээс баталгаажуулах цонх байдаг.
- **Нууц үг асуухаа больсон.** Таны эрх өөрөө зөвшөөрөл болно.
- Синхрончлол цаана ажиллана. «Sync эхэллээ» гэсэн бичиг гарвал ажил эхэлсэн
  гэсэн үг; үр дүн нь хэдэн минутын дараа **Баталгаажуулах** табд гарч ирнэ.
- Хоногт нэг удаа (Улаанбаатарын цагаар ~06:00) автоматаар ажилладаг тул энэ
  товчийг зөвхөн яаралтай үед ашиглана.

## 6. Баталгаажуулах таб *(зөвхөн Админ)*

Sync-ээр орж ирсэн баримтууд эндээс өнгөрч байж өгөгдлийн санд бичигдэнэ.
Дараалал дахь бичлэг бүр дээр:

- Эх файлын нэр, SharePoint дээрх байршил руу холбоос
- AI-аас задалж уншсан талбарууд, засварлаж болохоор

**Батлах** дарахад бичлэг `worker/data/heiwa.json`-д нэмэгдэж, GitHub руу commit
хийгдэнэ. Сайт автоматаар дахин build хийгдэж, шинэ мөр самбар дээр гарна.

**Цуцлах** дарвал бичлэг татгалзсан төлөвт орж, өгөгдлийн санд ордоггүй.

Анхаарах зүйлс:

- AI бүх талбарыг олж уншдаггүй (жишээ нь ангилал, системийн код, дотоод
  дугаарлалт). **Батлахаас өмнө дутуу талбаруудыг эх файлыг харж бөглөнө үү.**
- Батлах үед бичлэг самбарын өөрийнх нь шалгуураар шалгагдана. Талбар дутуу
  эсвэл буруу төрөлтэй бол алдаа заана.
- Батлагдсан бичлэгт эх файлын холбоос автоматаар хавсарна — гараар оруулах
  шаардлагагүй.

## 7. Хэрэглэгчид таб *(зөвхөн Админ)*

Зүүн цэсний **Хэрэглэгчид** табаар акаунт удирдана. (Тусдаа хаяг байхгүй —
энэ нь самбарын дотор таб хэлбэрээр байдаг.)

### Шинэ хэрэглэгч нэмэх

Дээд талын **Шинэ хэрэглэгч** хэсэгт:

1. Хэрэглэгчийн нэр
2. Түр нууц үг — **дор хаяж 10 тэмдэгт**
3. Эрх сонгох (Харагч / Синхрончлогч / Админ)
4. **Нэмэх**

Түр нууц үгийг эзэмшигчид нь дамжуулна. Нэр давхардвал «Энэ нэр аль хэдийн
бүртгэлтэй байна» гэж заана.

### Эрх өөрчлөх

Хүснэгтийн **Эрх** баганын сонголтоос шинэ эрхийг сонгоход шууд хадгалагдана.

### Нууц үг шинэчлэх

Мөрийн **Нууц үг солих** → шинэ нууц үг (10+ тэмдэгт) → **Хадгалах**.
Хуучин нууц үгийг мэдэх шаардлагагүй.

### Устгах

Мөрийн **Устгах** → баталгаажуулна. Устгасан хэрэглэгчийн нэвтрэлт тэр дороо
хүчингүй болно.

### Хориглосон үйлдлүүд

Систем дараах зүйлсийг зөвшөөрөхгүй, учир нь эрхээ буцааж өгөх хүнгүй үлдэх
эрсдэлтэй:

- Өөрийнхөө эрхийг бууруулах
- Өөрийгөө устгах
- **Сүүлийн үлдсэн Админыг** устгах эсвэл эрхийг нь бууруулах

### Өөрийн нууц үг солих

Хуудасны доод талын **Өөрийн нууц үг** хэсэгт одоогийн нууц үгээ, дараа нь
шинийг оруулна. Одоогийн нууц үгийг шаардах нь онгорхой үлдсэн дэлгэц дээрээс
хэн нэгэн таны акаунтыг булаахаас сэргийлнэ.

## 8. Түгээмэл асуудал

**Нэвтэрч чадахгүй байна.**
Хэрэглэгчийн нэрийн үсгийг шалгана (том/жижиг үсэг хамаагүй, гэхдээ үсгийн
алдаа чухал). Нууц үгийн том/жижиг үсэг чухал. Дахин болохгүй бол Админаар
нууц үгээ шинэчлүүлнэ.

**Өмнө нь нэвтэрдэг байсан, одоо гэнэт гарчихлаа.**
Нэвтрэлт 12 цагийн дараа дуусдаг. Дахин нэвтэрнэ.

**Таб гэнэт алга болов.**
Админ таны эрхийг өөрчилсөн байна. Баруун дээд булангаас одоогийн эрхээ харна.

**«Өгөгдөл ачаалж байна…» гэсээр байна, эсвэл алдаа заав.**
Нэвтрэлт дуусах үед ингэж болно. Хуудсыг дахин ачаална (F5). Үргэлжилвэл
Админд хандана.

**Мөрийн төгсгөлд OneDrive-ийн тэмдэг байхгүй.**
Тэр баримтын эх файлын холбоос хараахан бүртгэгдээгүй байна — 4-р хэсгийг
үзнэ үү. Алдаа биш.

**Sync дарсан ч Баталгаажуулах табд юу ч гарахгүй байна.**
Шинэ буюу өөрчлөгдсөн файл байхгүй бол хоосон байх нь хэвийн. Мөн задлалт
хэдэн минут үргэлжилдэг — түр хүлээгээд хуудсыг дахин ачаална.

**«Сүүлийн админыг устгах/бууруулах боломжгүй» гэж заав.**
Системд дор хаяж нэг Админ үлдэх ёстой. Эхлээд өөр хүнийг Админ болгоод,
дараа нь хүссэн өөрчлөлтөө хийнэ.

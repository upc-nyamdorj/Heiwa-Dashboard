# Хэйва хотхон — төслийн хяналтын самбар

**HEIWA RESIDENCE & CARE HOME** төслийн «UPH Heiwa Project» хавтасны 170 баримт
бичгээс гаргасан интерактив хяналтын самбар. Next.js 15 (App Router) +
TypeScript + Tailwind CSS v4 дээр бүтээсэн, статик экспорттой.

## Ажиллуулах

```bash
npm install
npm run dev      # http://localhost:3000 дээр хөгжүүлэлтийн горим
npm run build    # out/ хавтсанд статик хувилбар үүсгэнэ
npm start        # out/ хавтсыг локал сервэрээр үзүүлнэ
```

`out/index.html`-ийг браузераар шууд нээж болно (assetPrefix нь харьцангуй зам
ашигладаг тул `file://` дээр ажиллана).

## Юу харагдах вэ

| Хэсэг | Агуулга |
|---|---|
| **Тойм** | Гэрээний нийт дүн, санхүүжилтийн урсгал, гэрээт талуудын эрэмбэ, эрсдэлийн товч, гэрээний хугацааны Gantt |
| **Гэрээ** | 39 гэрээний бүртгэл, нэмэлт өөрчлөлт, санхүүжилтийн гүйцэтгэл %, гэрээ тус бүрийн дэлгэрэнгүй |
| **Санхүүжилт** | 70 тайлангийн дэвтэр, сарын cash-flow, төрлөөр задаргаа, тооцооллын аргачлал |
| **Баримт бичиг** | 170 файлын бүртгэл, ангилал × төрлийн матриц, дугаарлалтын хяналт |
| **Захидал / RFI** | Ирсэн/явсан урсгал, RFI хариу өгөх хугацаа, чанарын баримт |
| **Зургийн бүртгэл** | 55 багц / 2,083 хуудас, хэсэг × блокийн матриц, зохиогчийн статус |
| **Шалгалт** | Өгөгдлийн үнэн зөв байдал: 9 автомат шалгалтын үр дүн, талбар бүрийн эх сурвалж ба хамрах хүрээ, гараар шалгах жагсаалт |

Дээд талын товчоор цайвар/бараан горим солино. Хүснэгт бүр багана дээр дарж
эрэмбэлэгдэх, хайлт, шүүлттэй.

## Өгөгдөл хаанаас гарсан

`src/data/heiwa.json` дотор бүх өгөгдөл байна. Түүнийг гурван эх сурвалжаас
гаргасан:

1. **Файлын нэр (170 файл).** Баримтын дугаар, систем (BI / UPC / UPH), төрөл
   (CWA, CMA, IPR, LPR, EPR, EC, letter, RFI, акт), огноо, тал, ангилал, чиглэл
   (ирсэн/явсан) — бүгд файлын нэрний бүтцээс задарсан.
2. **Сканнердсан PDF (118 баримт).** PDF-үүд текст давхаргагүй тул хуудсуудыг
   зураг болгон хөрвүүлж, дүрс таних замаар уншсан:
   - Гэрээнээс: гэрээний дүн, валют, НӨАТ, хугацаа, урьдчилгаа %, баталгааны суутгал %.
   - Санхүүжилтийн тайлангаас: «Төлбөрийн хэмжээ, ₮», гэрээний дугаар, гэрээний
     хугацаа, ажил гүйцэтгэсэн хугацаа.
3. **«Зургийн бүртгэл Хэйва.xlsx».** 55 мөр — зохиогч, шифр, хуудасны тоо, блок,
   эх хувь / хуулбар / файлын байдал.

### Анхаарах ёстой шийдвэрүүд

- **Нэмэлт өөрчлөлт.** `-001` дугаартай гэрээ бүрийн эх бичвэрийг уншиж, тухайн
  нэмэлт нь *нэмэлт ажил үнэлсэн* (үндсэн дүн дээр нэмэгдэнэ) эсвэл *нийт дүнг
  шинэчилсэн* (үндсэн дүнг орлоно) эсэхийг тодорхойлсон. Энэ ялгааг
  `build_dataset.py` доторх `AMENDMENT_MODE` хүснэгтэд тайлбартай нь бичсэн.
- **Давхардал.** Тулга Хань болон Тунсаг Гарьд Мандалын эхлээд UPC дугаараар
  гарсан 4 тайлан дараа нь BI дугаараар дахин гарсан. Эдгээр ₮256,311,589-ийг
  нийт дүнгээс хассан (дэвтэрт зураастай харуулсан). «051 BI CMA Бат Ану Наран»
  файл хоёр хавтсанд байгааг гэрээний бүртгэлд нэг удаа тооцсон.
- **Нэгж үнэт гэрээ.** 4 гэрээ (АШК механизмын түрээс, Бат Ану Наран 052,
  Жи Эс Стийл 015, Хүрэл Гарди харуул) нийт дүнгүй, зөвхөн нэгж үнэтэй тул
  нийт дүнгийн тооцоонд ороогүй.
- **Гэрээний хугацаа.** Хэд хэдэн гэрээнд «баталгаажсанаас эхлэн» гэсэн заалттай
  тул огноо байхгүй. Ийм тохиолдолд санхүүжилтийн тайлангийн «Гэрээний хугацаа»
  мөрнөөс нөхөж авсан бөгөөд гэрээний дэлгэрэнгүйд `*` тэмдгээр заасан.

## Өгөгдлийг хэрхэн шалгах вэ

Дашбоардын **«Шалгалт»** таб дээр бүх зүйл байгаа. Товчхондоо гурван түвшин:

1. **Хөндлөнгийн дахин унших.** 12 баримтын дүнг тусад нь дахин уншиж тулгасан —
   бүгд таарсан, 3 зөрүү илэрч зассан.
2. **Дотоод логикийн шалгалт** (`audit.py`). Эх баримт нээхгүйгээр 9 төрлийн
   шалгалт: гэрээнээс их санхүүжилт, задаргаа нийлэхгүй, дугаар–огнооны зөрчил,
   ижил дүн давтагдах, гэрээ ба тайлангийн хугацааны зөрүү, дугаарын бичиглэлийн
   зөрүү, хугацаанаас хойш гарсан тайлан, уншигдаагүй дүн, сэжигтэй бүтэн тоо.
3. **Гараар шалгах жагсаалт.** Хамгийн их дүнтэй 20 баримт — тус бүрийн файлын
   зам, хаанаас харах, юуг батлах нь бичээстэй.

Тоо буруу байвал `src/data/heiwa.json`-оос шууд засаад `npm run build` —
нийлбэр, хувь бүгд дахин бодогдоно.

## Бүтэц

```
src/
  app/            layout, page (табын навигац), globals.css (өнгөний токен)
  components/     chart-kit.tsx (SVG анги, tooltip, card, stat tile)
                  charts.tsx   (багана, cash-flow, эрэмбэ, heatmap, Gantt)
                  DataTable.tsx (эрэмбэлэгддэг, хуудаслагддаг хүснэгт)
  views/          6 харагдац
  lib/            data.ts (нэгтгэл), format.ts, palette.ts, types.ts
  data/heiwa.json бүх өгөгдөл
```

Графикийн өнгө нь colorblind-safe категорийн палитр ашигладаг; цайвар, бараан
горим тус бүр өөрийн гадаргууд тохируулж баталгаажсан. Дэлгэрэнгүйг
`src/lib/palette.ts`-ээс үзнэ үү.

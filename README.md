# Heiwa Төслийн Dashboard

**HEIWA RESIDENCE & CARE HOME** төслийн «UPH Heiwa Project» хавтасны баримт
бичгээс гаргасан хяналтын самбар. Next.js 16 (App Router, статик экспорт) +
TypeScript + Tailwind CSS v4 -ээр бичиж, Cloudflare Worker дээр байршуулсан.

**https://heiwa-dashboard.nyamdorj-m.workers.dev**

Нэвтрэх шаардлагатай. Акаунтыг Админ үүсгэнэ.

## Ажиллуулах

```bash
npm install
npx wrangler dev   # Worker + D1 + статик assets — бүрэн ажиллагаатай
```

`npm run dev` (Next дангаараа) болон `npm start` (`npx serve out`) хоёр нь
зөвхөн статик гаралтыг үзүүлнэ. `/api/*` route байхгүй тул нэвтрэх дэлгэц
гарах боловч нэвтэрч чадахгүй. **Нэвтрэлт, өгөгдөл шаардсан бүх зүйлийг
`wrangler dev` дээр турших хэрэгтэй.**

```bash
npm run build      # out/ үүсгэж, дараа нь heiwa-dashboard.html-д inline хийнэ
npx tsc --noEmit
npx vitest run
npm run lint
```

## Архитектур, товчхон

```
OneDrive → GitHub Actions (хоногт нэг) → Claude API-аар задлах
         → data-private/pending-review.json
         → Админ батлах → worker/data/heiwa.json → git push
         → Cloudflare дахин build → Worker (/api/* + статик assets)
```

`output: "export"` тул Next нь зөвхөн build хийх үед ажиллана. Бүх сервер
талын логик `worker/index.ts`-ийн router дотор. OpenNext ашигладаггүй.

**Өгөгдөл нийтийн bundle дотор байдаггүй.** `worker/data/heiwa.json` нь
Worker-ийн bundle-д байх бөгөөд зөвхөн `GET /api/data`-аар, нэвтэрсэн
хэрэглэгчид олгогдоно.

## Эрхийн систем

Гурван түвшин: **Харагч** (самбар харна), **Синхрончлогч** (+ Sync),
**Админ** (+ Баталгаажуулах, Хэрэглэгчид).

Акаунтууд Cloudflare D1 дотор, нууц үг PBKDF2-оор hash хийгдсэн. Session cookie
дотор зөвхөн хэрэглэгчийн id байх бөгөөд эрхийг хүсэлт бүрд өгөгдлийн сангаас
уншдаг тул эрхийн өөрчлөлт шууд үйлчилнэ.

Анхны Админ үүсгэх:

```bash
node scripts/create-admin.mjs
```

## Deploy

`main` руу push хийх нь **автоматаар deploy хийнэ** (Cloudflare Workers Builds).
Шууд гаргах бол:

```bash
npm run build && npx wrangler deploy
```

Secret болон орчны хувьсагчийн бүрэн жагсаалтыг
[`docs/technical-guide.md`](docs/technical-guide.md)-ээс үзнэ үү.

мөрийн төгсгөлд OneDrive руу шилжих тэмдэг гарна.

## Өгөгдөл хаанаас гарсан

> **Устгагдсан скриптүүд.** Доор дурдсан `build_dataset.py`, `audit.py` хоёр нь
> `heiwa.json`-ыг нэг удаа PDF/xlsx эх сурвалжаас гаргахад ашиглагдсан боловч
> энэ репозиторид байхгүй. Дахин ажиллуулах боломжгүй тул эдгээрийн үр дүнг
> зөвхөн гараар засварлана.

`worker/data/heiwa.json` дотор бүх өгөгдөл байна. Гурван эх сурвалжаас гарсан:

1. **Файлын нэр.** Баримтын дугаар, систем (BI / UPC / UPH), төрөл (CWA, CMA,
   IPR, LPR, EPR, EC, letter, RFI, акт), огноо, тал, ангилал, чиглэл —
   бүгд файлын нэрний бүтцээс задарсан.
2. **Сканнердсан PDF.** Текст давхаргагүй тул хуудсуудыг зураг болгон хөрвүүлж,
   дүрс таних замаар уншсан. Гэрээнээс: дүн, валют, НӨАТ, хугацаа, урьдчилгаа %,
   баталгааны суутгал %. Тайлангаас: төлбөрийн хэмжээ, гэрээний дугаар, хугацаа.
3. **«Зургийн бүртгэл Хэйва.xlsx».** Зохиогч, шифр, хуудасны тоо, блок,
   эх хувь / хуулбар / файлын байдал.

Шинэ баримт одоо OneDrive sync-ээр орж ирж, Claude API-аар задарч,
**Баталгаажуулах** табаар батлагдаж байж энэ файлд нэмэгддэг.

### Анхаарах ёстой шийдвэрүүд

- **Нэмэлт өөрчлөлт.** `-001` дугаартай гэрээ бүрийн эх бичвэрийг уншиж, тухайн
  нэмэлт нь *нэмэлт ажил үнэлсэн* (үндсэн дүн дээр нэмэгдэнэ) эсвэл *нийт дүнг
  шинэчилсэн* (үндсэн дүнг орлоно) эсэхийг тодорхойлсон. `Amendment.mode`
  талбарын утга (`add` / `replace` / `none`) нь гараар засварлаж хадгалагдсан
  эцсийн үр дүн.
- **Давхардал.** Тулга Хань болон Тунсаг Гарьд Мандалын эхлээд UPC дугаараар
  гарсан 4 тайлан дараа нь BI дугаараар дахин гарсан. Эдгээр ₮256,311,589-ийг
  нийт дүнгээс хассан. «051 BI CMA Бат Ану Наран» файл хоёр хавтсанд байгааг
  гэрээний бүртгэлд нэг удаа тооцсон.
- **Нэгж үнэт гэрээ.** 4 гэрээ (АШК механизмын түрээс, Бат Ану Наран 052,
  Жи Эс Стийл 015, Хүрэл Гарди харуул) нийт дүнгүй, зөвхөн нэгж үнэтэй тул
  нийт дүнгийн тооцоонд ороогүй.
- **Гэрээний хугацаа.** Хэд хэдэн гэрээнд «баталгаажсанаас эхлэн» гэсэн заалттай
  тул огноо байхгүй. Санхүүжилтийн тайлангийн «Гэрээний хугацаа» мөрнөөс нөхөж
  авсан бөгөөд гэрээний дэлгэрэнгүйд `*` тэмдгээр заасан.

## Өгөгдлийг хэрхэн шалгах вэ

**Шалгалт** таб дээр гурван түвшний шалгалт байна:

1. **Хөндлөнгийн дахин унших.** 12 баримтын дүнг тусад нь дахин уншиж тулгасан —
   3 зөрүү илэрч зассан.
2. **Дотоод логикийн шалгалт.** 9 төрлийн шалгалт: гэрээнээс их санхүүжилт,
   задаргаа нийлэхгүй, дугаар–огнооны зөрчил, ижил дүн давтагдах, хугацааны
   зөрүү, дугаарын бичиглэлийн зөрүү, хугацаанаас хойш гарсан тайлан, уншигдаагүй
   дүн, сэжигтэй бүтэн тоо. Үр дүн нь `heiwa.json`-ы `audit` массивт хадгалагдсан;
   шалгалтыг ажиллуулсан `audit.py` репозиторид байхгүй тул дахин автоматаар
   ажиллуулах боломжгүй.
3. **Гараар шалгах жагсаалт.** Хамгийн их дүнтэй 20 баримт — файлын зам,
   хаанаас харах, юуг батлах нь бичээстэй.

Тоо буруу бол `worker/data/heiwa.json`-оос шууд засаад `npm run build` —
нийлбэр, хувь бүгд дахин бодогдоно.
